# RustyCord Native (GPUI-спайк)

Экспериментальная ветка `gpui-spike`: нативный интерфейс RustyCord на
[GPUI](https://gpui.rs) (GPU-ускоренный UI-фреймворк от авторов Zed),
без вебвью.

**Это не продукт.** Продукт — Tauri-клиент в `src-tauri/` + `src/`,
он продолжает релизиться. Спайк отвечает на вопрос «стоит ли вкладываться
в полный переезд на GPUI», и только после зелёного ответа начинается
миграция (план фаз — в PR-описании ветки).

## Что уже есть

- Discord-тёмная раскладка: рельса серверов, список каналов, лента, поле ввода
- Интерактив: выбор сервера/канала (entity-модель GPUI, перерисовка)
- Кириллица, юнит-тесты, CI-джоба `native`

## Что дальше (порядок)

1. Текстовый ввод с IME — адаптация input-примера GPUI (Apache-2.0)
2. `List`-виртуализация ленты, `Img` для аватаров
3. Рефакторинг `rustycord_lib`: `EventSink`-трейт вместо `tauri::Emitter`
   (48 emit-точек) → подключение реального шлюза к этому UI
4. Капча через `wry` standalone, апдейтер (`self_update`), трей (`tray-icon`)

## Запуск (локально)

```bash
cd native && cargo run
# Linux: нужен Vulkan-стек; Wayland/X11, как у Zed
```
